Gelasio (Eben Sorkin) and Arimo (Steve Matteson), from Google Fonts, under
the SIL Open Font License 1.1 (https://openfontlicense.org). They stand in
for Georgia and Arial, with the same metrics, in the Lesson Deck Kit's PDFs
(lesson plans and handouts), since Georgia and Arial cannot be embedded.

Fraunces Bold (The Fraunces Project Authors, github.com/undercasetype/Fraunces),
under the SIL Open Font License 1.1 (Fraunces-OFL.txt). The Lesson Deck Kit,
spec v4.1, sets titles and headlines in it: the static instance at wght 700,
SOFT 100, WONK 1, opsz 72 of the Google Fonts variable font (latin and
latin-ext), named family "Fraunces", style "Bold". Present and the thumbnails
load the .woff2, the PDFs register the .ttf, and every PowerPoint export
embeds the .ttf so it shows where Fraunces is not installed.
