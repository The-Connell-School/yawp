Assignment sheet — grading configuration

Five structurally different answers to the same block. Deliberately grayscale and low fidelity — the point is layout and information hierarchy, not final styling. Each frame is drawn at the real sheet width so the comparison is honest.

What is actually wrong today

  1. 01 Four separate places show a point number: Default point value, Rubric default, Total Point Values, and Grading Total. A teacher cannot tell which one wins.
  2. 02 The scoring mode is stated twice — once as a read-only Default grading type box shaped like a dropdown, then again as the Scoring behavior picker that actually controls it.
  3. 03 Three levels of nested containers — checkbox panel, section, then the Customize Grading card — produce a stack of gray boxes with no hierarchy.
  4. 04 Customize Grading is a gate in front of two fields. It costs a click and a mental model to reach settings that could simply be editable.
  5. 05 Both pickers print a full sentence on every card, so the densest, loudest elements on the sheet are explanations rather than the choice itself.

Option A

Flat settings rows

Delete the Customize Grading gate. Three editable rows separated by hairlines, one line of help under the row it belongs to, no nested boxes at all.

Decisions these options are really asking about

  • Does Customize Grading survive at all? A, C, D and E delete it; B keeps the idea but reframes it as a summary you open.
  • Is there one point number or two? Every option assumes one editable value with the rubric default shown as a hint. That contradicts the current durable decision to keep the default read-only.
  • Do the choice descriptions belong on the control, beside it, or under the selected value only? That single call drives most of the height difference between these five.
  • Does this stay in a narrow right-hand sheet? C and E want more width. If the sheet is fixed, A, B and D are the realistic candidates.
