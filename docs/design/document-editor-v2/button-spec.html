Button

The Yawp! button is printed, not floating: a flat brand-green fill with a fine rim and a pressed-in bottom edge, like type set into paper. It replaces the terracotta, coral and gold buttons across the app. One look, five variants, three sizes, every state below.

Anatomy

  1. Fill · brand green #1f4d3a, flat. No gradient.
  2. Rim · 1 px inside edge in a darker green, so it holds its shape on white and cream.
  3. Top highlight · 1 px light line inside the top edge, 12 % white. Reads as paper catching light.
  4. Pressed-in edge · 2 px darker line inside the bottom edge. This is the letterpress feel: stamped into the page, not raised off it.
  5. Label · 600 weight, cream, faint 1 px dark text shadow. Pill radius at every size.

Rules

  • One primary button per screen or panel. If two actions both look primary, one of them is secondary.
  • Labels are verbs that say what happens: "Create assignment", not "Submit form". The success label uses the same verb ("Saved" after "Save changes").
  • Sentence case, no trailing arrows in text. Use the trailing arrow icon only for "go to the next place".
  • Disabled buttons explain themselves: keep them focusable (aria-disabled) and give a tooltip with the reason.
  • Never colour-only meaning: destructive buttons also say what they destroy ("Delete assignment").
  • Gold, terracotta and coral are no longer button colours. Coral stays for small accents only where it already lives.
